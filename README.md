# Pizza na Wypasie CRM Прототип

Клікабельний HTML/CSS + Ruby on Rails прототип на основі наданих користувацьких історій.

## Скоуп прототипу

- Один адмінський кабінет для керування піцерією.
- Додавання додаткових користувачів у розділі `Налаштування`.
- Модулі: дашборд, склад, інгредієнти, рецепти, поставки, замовлення з авто-списанням, ручні списання, сповіщення, звіти та налаштування.
- Rails-каркас: маршрути, контролер, макети та ERB-екрани, що відповідають статичному експорту.

## Статичний перегляд

Статичний експорт доступний з `index.html` і працює на поточному локальному сервері:

```text
http://127.0.0.1:4174/
```

## Rails-прототип

- `Gemfile`
- `config/routes.rb`
- `app/controllers/prototype_controller.rb`
- `app/views/layouts/application.html.erb`
- `app/views/layouts/auth.html.erb`
- `app/views/prototype/*.html.erb`
- `app/assets/stylesheets/prototype.css`

## Як запустити Rails

Коли Rails-залежності встановлені:

```bash
bundle install
bin/rails server
```

Потім відкрий:

```text
http://127.0.0.1:3000/
```

## Продуктові нотатки

Усі процеси зі змінами даних представлені лише як UI-прототипи. Реальна реалізація має проводити всі зміни залишків через єдиний сервіс, який записує `stock_movements`, використовує транзакції бази даних, застосовує FEFO і створює сповіщення та події журналу аудиту.
